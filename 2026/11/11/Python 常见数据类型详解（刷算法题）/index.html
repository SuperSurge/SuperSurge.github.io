八、总结对比表

类型 可变 有序 唯一 可哈希 常用场景
int/float/bool ✗ — — ✓ 数值计算
str ✗ ✓ ✗ ✓ 文本
list ✓ ✓ ✗ ✗ 有序可变集合
tuple ✗ ✓ ✗ ✓(元素可哈希) 固定结构、字典键
dict ✓ ✓(3.7+) Key唯一 ✗ 键值映射
set ✓ ✗ ✓ ✗ 去重、集合运算
frozenset ✗ ✗ ✓ ✓ 可哈希集合

选型建议：

  • 需要顺序 + 修改 → list
  • 需要顺序 + 不可变 → tuple
  • 需要键值查找 → dict
  • 需要去重/集合运算 → set
  • 大量文本处理 → str 及其方法
